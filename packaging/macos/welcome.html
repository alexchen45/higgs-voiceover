Higgs VoiceOver adds AI voice-over to DaVinci Resolve, powered by Boson's Higgs TTS 3.

This installs one script into DaVinci Resolve's Scripts menu for every user on this Mac. Nothing else is added to your system.

You'll need DaVinci Resolve (from blackmagicdesign.com) and a Boson API key, which you can add the first time you open it.
